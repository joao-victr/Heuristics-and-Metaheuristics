# Heurísticas e Metaheurísticas

Implementações de algoritmos de otimização aplicados a problemas clássicos de otimização combinatória.

O repositório reúne diferentes abordagens para encontrar soluções aproximadas para problemas computacionalmente difíceis, com foco na implementação, experimentação e análise dos algoritmos.

## Problemas

### 🧭 Problema do Caixeiro Viajante (TSP)

O **Travelling Salesman Problem (TSP)** consiste em encontrar uma rota de menor custo que visite um conjunto de cidades exatamente uma vez e retorne à cidade de origem.

Neste problema, os algoritmos trabalham sobre uma representação de solução baseada em uma **permutação das cidades**.

### 🎒 Problema da Mochila Binária

O **Problema da Mochila Binária (0/1 Knapsack Problem)** consiste em selecionar um conjunto de itens, cada um podendo ser escolhido ou não, de forma a maximizar o valor total sem ultrapassar a capacidade disponível da mochila.

As soluções são representadas por vetores binários, onde cada posição indica se determinado item foi selecionado.
